Déploiement d'Infrastructures

Windows Server, pfSense en redondance et NAS TrueNAS

Par : YANG Liam

Présentation de la documentation

Objectif : Ce guide rassemble les procédures étape par étape pour déployer trois services essentiels au sein d'une infrastructure réseau virtualisée sous VMware : un contrôleur de domaine Windows Server, un pare-feu pfSense en haute disponibilité et un serveur de stockage NAS.

1 Déploiement Windows Server 2022

Création d'un serveur Windows 2022 avec AD DS, DHCP et DNS depuis une machine virtuelle avec VMWare.

Étape 1 : Préparation de l'environnement

  • Téléchargement de l'hyperviseur VMWare Workstation 17 et de l'ISO officiel de Windows Server 2022.

Étape 2 : Création de la Machine Virtuelle

  • Dans VMWare, cliquer sur « File » puis « New Virtual Machine… » et choisir la configuration « Typical » pour créer la VM facilement.

Étape 3 : Assignation de l'ISO

  • Lors du choix de l'installation de l'ISO, sélectionner l'option « I will install the operating system later » (Choisir l'iso plus tard).
  • Cette méthode est recommandée pour éviter que VMWare ne détecte pas correctement la bonne version de l'ISO.

2 Configuration pfSense en redondance

Mise en place d'un Pfsense-main et d'un Pfsense-secondary.

Étape 1 : Configuration des cartes réseaux

  • La machine doit être configurée avec 3 cartes réseaux : WAN, LAN et pfsync.

Étape 2 : Lancement et Installation

  • Démarrer la machine et faire « Accept » puis choisir « Install pfSense ».
  • Pour le partitionnement, sélectionner « Auto UFS » en utilisant le disque entier.
  • Dans « Partition Scheme », opter pour « MBR DOS ».
  • Valider avec « Commit » puis redémarrer (Reboot) la machine à la fin du chargement.

Étape 3 : Adressage IP

  • Sur le menu principal de pfSense, utiliser l'option 1 pour assigner les cartes réseaux.
  • Utiliser l'option 2 pour appliquer une adresse IP sur chaque interface.

3 Configuration Serveur NAS

Création et configuration d'un serveur NAS sous Debian 12 en utilisant TrueNAS.

Étape 1 : Préparation des disques

  • Récupération de l'ISO TrueNAS depuis le site officiel.
  • Allocation de 3 disques à la machine virtuelle : le premier pour le système d'exploitation, le deuxième pour le stockage, et le troisième en redondance (copie du 2e en cas de panne).

Étape 2 : Installation de l'OS

  • Choisir l'option 1 « Install/Upgrade » et sélectionner le premier disque pour installer le système d'exploitation.

Étape 3 : Sécurisation et Redémarrage

  • Définir un mot de passe fort pour le compte administrateur (Attention : l'interface d'installation utilise un clavier QWERTY).
  • Une fois l'installation terminée, redémarrer la machine.

Étape 4 : Interface Web

  • Après le redémarrage, se connecter à l'interface web via l'identifiant truenas_admin et le mot de passe renseigné lors de l'installation.
